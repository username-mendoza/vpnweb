Connection Profiles

New Profile
The host/hint format (e.g. 81.2.3.4/192.168.1.5) is used by the native SoftEther client to distinguish servers on the same LAN via its binary protocol. This web interface uses the JSON-RPC HTTP API, which does not support hints. To reach two servers behind the same public IP, configure different external ports (e.g. :5555 and :5556) via port forwarding. The hint part will be removed.
VPN Azure addresses (vpnazure.net) are not supported. VPN Azure is a relay service that requires SoftEther's proprietary relay protocol — direct JSON-RPC connections are not possible through it. Use the server's direct IP or softether.net DDNS hostname instead.
